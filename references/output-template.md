# Client-facing Output Template

| Section | Include | Exclude |
| --- | --- | --- |
| Current understanding | Source-labelled summary of purpose and context | Unconfirmed facts stated as certainty |
| Confirmed requirements | Objective, audiences, scope, delivery, and constraints | Internal ideas presented as client decisions |
| Input readiness | Available/missing input, reason, timing, and suggested owner | Irrelevant exhaustive checklists |
| Confirmation questions | Focused question, decision impact, and desired response format | Questions the team can resolve through normal work |
| Team work items | Research, strategy, content, design, or feasibility tasks | Work items presented as client-approved requirements |
| Risks and boundaries | Scope, timing, cost, approval, rights, safety, feasibility, and acceptance | Creative uncertainty framed as failure |
| Next actions | Ordered client and team actions | Unauthorized commitments |
